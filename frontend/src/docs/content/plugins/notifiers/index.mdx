---
title: Notifications
description: Durable in-app notifications and Electron toasts built into AO.
---

Notifications are a daemon and desktop capability, not a configurable plugin slot. Orchestrator currently persists notifications for these lifecycle events:

- a session needs input;
- a pull request is ready to merge;
- a pull request was merged;
- a pull request closed without merging.

In the desktop app, the notification center shows a newest-first feed and loads older alerts as you scroll. Opening it resets the bell badge while unread alerts stay highlighted. Selecting an alert marks only that alert read and opens its session or pull request when available. Use Clear all to dismiss the feed, or choose Clear all after this from a row’s context menu to dismiss that row and all older notifications, including unloaded history. New alerts can also appear as desktop toasts while the app is running.

Slack, Discord, generic webhook, Composio, OpenClaw, and standalone desktop notifier configuration from the legacy TypeScript release are not supported in the rewrite.

See [notification center](/plugins/notifiers/dashboard) for controls and mobile push details.
